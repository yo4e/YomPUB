# 三冊の小さな本

全原稿・幾何図形はこのプロジェクトのためのオリジナル検証素材（MIT）です。アラビア語/ヘブライ語は方向・文字保存を試す短い文であり、母語話者による校閲済みの教材とはしていません。

| フォルダ | 素の原稿で見ること | viewerで見ること |
| --- | --- | --- |
| [horizontal](horizontal/book.md) | 表紙なし、h1/h2/h1、引用、リスト、強調、コード、内部/外部リンク、alt | 目次3項目、画像、文字サイズ変更後も本文が読める |
| [vertical](vertical/book.md) | `ja`/`ltr`/`vertical-rl`の独立性、表紙と本文画像、見出し/隣接語のルビ、記号エスケープ | 右から左へ列が進み、ルビが各語の右側、目次から第二章へ移動 |
| [rtl](rtl/book.md) | アラビア語基本方向、英語/ヘブライ語の言語範囲、URL・数字・括弧 | 基本文がRTL、英語の名前/URLはLTRのまま、文字列を逆転しない |

全冊の見出しIDは `h-1`, `h-2`, `h-3`。`#h-3` は第三の見出し（第二章）です。書誌タイトルは目次には含みません。

画像を交換するときは各フォルダ全体をコピーします。原稿の保存ボタンはbook.md単体の保存であり、画像を含むパッケージではありません。図形は `node scripts/make-sample-images.mjs` で同じPNGを再生成できます。

追加の境界例は `tests/fixtures/conformance.json`。全冊のAST投影は `tests/fixtures/{horizontal,vertical,rtl}.ast.json` です。後者は参照実装から作成して内容を検査した回帰fixtureであり、独立実装との一致を証明するものではありません。
